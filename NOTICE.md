# Public showcase notice

This repository contains the product interface, agent workflow, prompt orchestration and retrieval implementation used by Arcana Oracle.

The production knowledge corpus, book-derived interpretations, embeddings, source documents and production card artwork are intentionally excluded. The files in `data/` and `js/cards-knowledge.js` contain concise demonstration content written for this public repository. They show the expected schema and make the project runnable, but they are not the production corpus.
